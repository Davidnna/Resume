FEATURED PROJECT · MARQUEE

Helping local makers move from discovery to a useful first request.

Marquee is a discovery and commission website for independent local makers in Nigeria. The product responds to a simple gap: creative work can be easy to discover on social media while the practical details needed to commission it remain scattered.

Each maker profile brings together craft, location, selected work, starting price, turnaround, availability and commission notes. A structured request flow then helps the buyer provide the information a maker needs to begin a useful conversation.

HTML & CSS Static multi-page No JavaScript Responsive UI
